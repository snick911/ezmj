# EZMJ 台灣十六張麻將

以 Java Swing 製作的台灣十六張麻將。需要 JDK 17 以上才能建置。

## 建置與打包

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

腳本會編譯、執行全部測試（失敗就中止），再把成品放到 `dist\`：

| 檔案 | 說明 |
|---|---|
| `ezmj-<版號>.jar` | 可執行 jar，需要 Java 17 以上：`java -jar ezmj-<版號>.jar` |
| `EZMJ-<版號>-windows-portable.zip` | 免安裝版，解壓後執行 `EZMJ.exe`，不需要另外裝 Java |
| `EZMJ-<版號>-setup.exe` | 安裝程式，需要 WiX 3 才會產生 |

版號只改 `src/ezmj/version.properties` 一處。

要產生安裝程式時，把 [WiX v3.14.1](https://github.com/wixtoolset/wix3/releases/tag/wix3141rtm) 的 `wix314-binaries.zip` 解壓到 `tools\wix314\`（不進版控），或把 WiX 3 加到 PATH。

### 打包流程

每次打包前依序做：

1. 看修改內容：`git status` 與 `git diff`，連同還沒 commit 的新檔案，確認這次會包進去的東西。
2. 記下修改內容：寫進 `CHANGELOG.md`，把「未發布」改成 `## <新版號> - <日期>`，再開一個新的「未發布」。
3. 版號增加：改 `src/ezmj/version.properties`，依下面的規則決定動哪一碼。
4. 執行 `build.ps1`。

版號是 `主版.次版.修正`，看這次修改裡影響最大的一項：

| 動哪一碼 | 什麼時候 | 例子 |
|---|---|---|
| 主版（1.0.0） | 大改版，或舊的設定、榮譽榜、成就讀不回來 | 存檔格式不相容、整個換介面 |
| 次版（0.2.0） | 新功能，或改變牌局規則、計台 | 新的牌型、新的選單、新的設定 |
| 修正（0.1.1） | 只有修錯、調整文字或外觀，規則和功能都不變 | 修程式錯誤、改說明、調整排版 |

動了前面的碼，後面的碼歸零。

`CHANGELOG.md` 沒有這個版號的段落，或 `dist\` 已經有這個版號的成品時，腳本會直接停止，不會清除任何檔案。確定要用同版號重新打包，先刪除 `dist\`。

## 測試

測試不依賴框架，直接執行 `test/ezmj/AllTests.java` 的 `main` 即可。

`RefereeTest` 照「基本規則」與「台數計算」的文字另外實作一套規則，和引擎逐步比對。改規則時，說明、`Scorer`／`Round` 與這份裁判要一起改。

`OnlineTest` 測連線層，對面是測試自己開的假服務器，走真的 TCP 與 WebSocket，同一批測試兩種連線各跑一次。協定改了要和 `ezmjService` 的 README 一起看。

## 程式結構

| 套件 | 職責 |
|---|---|
| `ezmj.model` | 牌、牌牆、骰子、面子、玩家、設定 |
| `ezmj.rules` | 胡牌判定、計台 |
| `ezmj.engine` | 單局流程、整場牌局與結算（不依賴 Swing） |
| `ezmj.bot` | 電腦玩家：四個等級的思考邏輯 |
| `ezmj.table` | 一桌牌的行牌流程：輪到誰、等誰決定、倒數與代打（不依賴 Swing，可有多位真人） |
| `ezmj.online` | 連線對戰的客戶端：TCP 與 WebSocket 連線、登入、ping 與重連，把服務器的訊息翻成局面（不依賴 Swing，不算規則） |
| `ezmj.ui` | Swing 畫面，把牌桌流程演出來 |

牌桌畫面只讀 `engine.RoundView` 與 `engine.GameView`，不管局面從哪裡來：單機是 `Round` 與 `GameSession`，連線是 `online.OnlineGame`。動畫、音效與按鈕都在 `ui.TablePresenter`，局面來源與決定的去處由它的 `Table` 介面決定：單機是 `GameController`，連線是 `OnlineController`。畫面上的座位 0 一定是自己，連線時服務器的座位在 `OnlineGame` 就轉好了。

## 連線對戰

開始畫面按「連線對戰」進大廳，輸入名字，就可以從列表挑一間公開的房間加入、用六碼房號加入，或開一間新房間。規則全部在服務器上跑，客戶端只送決定。

服務器固定是部署在 Render 的 [EZMJ Server](https://github.com/snick911/ezmjService)（`wss://ezmj-server.onrender.com/ws`），畫面上不能改，也不會從設定檔讀。免費主機閒置後會睡著，第一個連線可能要等一分鐘。

測試時用系統屬性換服務器，不要碰到線上的：`-Dezmj.server=<位址>`。位址有兩種寫法：`host` 或 `host:port` 走 TCP，預設 port 7788；`ws://` 或 `wss://` 開頭的網址走 WebSocket。`OnlineTrial` 會自己帶上這個屬性。打包好的 `EZMJ.exe` 沒辦法直接帶參數，要測的話設環境變數 `JAVA_TOOL_OPTIONS=-Dezmj.server=<位址>`。

- **大廳**：列出等人中、還有空位的公開房間，有房間名稱、房主、人數、籌碼／底／台與每次等待秒數，新開的在前面，最多 50 間。選一間按「加入」或連點兩下就加入。待在這個畫面時每 5 秒更新一次，也可以按「重新整理」。列表走一條不登入的連線，服務器不會主動推送；舊服務器不認得列表時只顯示一句說明，用房號加入和開房間照樣能用。
- **開房間**：選房間名稱（最多 30 字，空白就用「<名字>的房間」）、要不要設成私人房間、籌碼本金、底、每台、補位電腦的等級、每次等待秒數（5 到 300，多人桌不能不限時）與電腦速度。私人房間不列在大廳，只能用房號加入。房間畫面顯示房間名稱與房號，私人房間標著「私人」，把房號告訴朋友就好；畫面也會列出玩家與連線狀態。
- **開局**：只有房主可以，不到四人由電腦補滿。打完整場回到房間，可以再開一場。
- **結果視窗**：大家都看完就開下一局，沒看完時最多等服務器的時間（流局 5 秒，其他 15 秒）。
- **電腦代打**：多人遊戲不能用，牌桌上沒有這顆按鈕，服務器也會拒絕。斷線或離開的座位才由電腦接手。

等待時間與速度看房間的設定，環境設定裡的兩項只影響單機。平均思考時間只有單機才有，連線牌局那一行顯示房號。

**斷線重連**：連線斷了會自己重連，最多試 3 分鐘，這段時間座位由電腦代打，別人會看到名字旁標著「（斷線）」。接回來時局面、還在等你決定的詢問都會補上。程式被關掉的話，重開之後按「連線對戰」的「接回牌局」。還沒開局時斷線就等於離開房間，牌局中按「離開牌局」也回不來了。

**存檔**：連線牌局不寫入本機的牌局存檔、統計、成就與榮譽榜。輸贏歷程只記這次開著程式時看到的局。使用者目錄的 `.ezmj\online.properties` 記著上次的名字；牌局中還有 token 與房號，牌局結束就清掉。token 等於這個座位的身分，不要給別人。

連線都走 `wss://`，有加密。測試時用的 `host:port` 與 `ws://` 是明碼，只適合本機或信任的網路。

要實際跑一遍，先編好 `ezmjService`，再用下面的指令開一台服務器和好幾個視窗，自己按按鈕打牌，驗證開房、從大廳加入、私人房間不列在大廳、用房號加入、打完整場、斷線重連與殺掉程式後接回。截圖與紀錄都在輸出資料夾，不會碰到真正的設定與存檔：

```
java -cp build\classes;build\test-classes ezmj.ui.OnlineTrial <服務器的 classpath> <輸出資料夾>
```

## 環境設定

選單「環境設定」的選擇會存到使用者目錄的 `.ezmj\settings.properties`，刪除這個檔案就回到預設值。

| 設定 | 預設 | 說明 |
|---|---|---|
| 字體大小 | 100% | 85% 到 150%，立刻套用。牌面上的字不跟著變 |
| 麻將大小 | 100% | 100% 到 150%，立刻套用。視窗寬度不夠時手牌會稍微重疊，最多疊到牌寬的約兩成，再大就要把視窗放大才看得出差別 |
| 等待時間 | -1 | 真人每次可以考慮的秒數，-1 表示不限時。時間到還沒決定：吃、碰、槓、胡視為放棄，輪到出牌則打出最右邊的手牌（也就是放棄自摸與槓） |
| 遊戲速度 | 中 | 慢、中、快，電腦出牌前與等宣告時停多久，改了下一個動作就生效 |
| 解析度 | 1360 × 900 | 視窗大小或最大化。放不進螢幕的選項不能選 |
| 背景音樂 | 茶館閒情 | 四首原創曲子或關閉，樂譜在 `MusicScores`，由 `BackgroundMusic` 合成，不需要音樂檔 |
| 音量 | 音樂 50、音效 100、語音 100 | 分別調整，0 到 100，拉動時立刻生效 |
| 音效 | 開 | 打牌、吃碰槓、胡牌與流局的聲音，由 `SoundEffects` 合成，沒有音效裝置時不出聲 |
| 語音 | 開 | 喊打出的牌，以及吃、碰、槓、胡、自摸、聽牌、流局。電腦角色隨機男女，各用男聲或女聲。第一次用 Windows 內建的中文語音產生，存在 `.ezmj\voice`，刪除後會重新產生；沒有中文語音或不是 Windows 時選項會停用 |
| 我的語音 | 女聲 | 自己喊牌用女聲或男聲，選了會喊一聲試聽，牌局中改也立刻生效 |
| 動畫 | 開 | 擲骰子、發牌、牌的飛行與大字，只影響畫面，不影響牌局結果。關閉時立刻開局，胡牌後也立刻跳出結果 |

## 籌碼、底與台

單機的開始畫面與連線開房用同一組選項：

| 設定 | 選項 |
|---|---|
| 籌碼本金 | 10000、20000、50000、100000、500000、1000000、5000000、10000000 |
| 底 | 50、100、300、500、1000、5000、10000、50000、100000、500000、1000000 |
| 每台 | 10、20、50、100、200、5000、10000、50000、100000、200000、500000、1000000 |

底和每台都不能大於籌碼本金，等於可以。不符合時開始遊戲與開房間的按鈕會停用，並顯示「底和每台不能大於籌碼本金」。`GameConfig` 也照這條規則檢查，讀到不符合的存檔就當作讀不出來；連線時服務器也會檢查。

金額都用 `int`，最大的選項也放得下：每一筆付款是底 ＋ 台數 × 每台，籌碼本金一千萬、底與每台一百萬時，自摸三家付要到一家 700 多台才會超過，牌型台數加起來不到 100 台，剩下的要靠連莊超過 300 次。統計的累計輸贏會一直加上去，所以是 `long`。

## 結果與牌局結束

胡牌時牌桌中間跳出大字，分成三種：

| 種類 | 樣子 | 時間 |
|---|---|---|
| 胡別家打出的牌 | 金字深底框，三個金色的圈接連往外擴散 | 1.1 秒 |
| 自摸 | 金字深底框，後面一團變大的金光與 16 道慢慢轉的金紅光芒 | 1.4 秒 |
| 大胡（牌型台數 10 台以上，胡或自摸都算） | 紅色漸層框，字下面多寫台數，字放大後會跳動；一開始紅金閃一下，24 道金白光芒，彩片往外噴再落下 | 2.4 秒 |

台數是結果視窗的「牌型合計」，不算莊家台。流局只有灰字，1.1 秒。結果視窗等大字演完才跳出來，連線時倒數會扣掉這段時間。「動畫」關閉時不演，立刻跳出結果。

每局結果視窗會倒數，時間到自動進入下一局：流局 10 秒，其他 60 秒，也可以直接按按鈕。視窗也列出其他家的手牌，放槍的人會標出來。

四圈打完或有人籌碼輸到 0 以下，牌局就結束。結束視窗顯示結束原因、總局數與流局數，以及四家的名次、胡牌、自摸、放槍、輸贏與籌碼。

牌桌右側的「輸贏歷程」列出這場每一局的圈風、莊家、結果、牌型台數、四家輸贏與自己的累計，滑鼠停在結果上可以看牌型。開著也能繼續打，牌局結束視窗也能查看。歷程不存檔，離開牌局就清除。

牌桌中間與右側上方顯示圈風和局風，例如「東風南局」。局風依起莊算：莊家是起莊那位時是東局，下莊一次就往下一局，連莊時不變，四局打完換圈又回到東局。右側那行後面再接連莊次數，例如「東風南局 連1」。連線時舊服務器沒有送局風，就照以前顯示「東風圈」。

牌桌右側的表格列出四家的門風、玩家與籌碼，莊家在門風後面標著紅色圓圈框住的紅字「莊」。牌桌上名字旁邊的「莊」照舊。

牌桌右側也會顯示自己的平均思考時間：從摸牌或可以吃碰槓胡開始，到打出牌、胡或決定過為止。吃碰槓之後要打出牌才算一次。電腦代打與報聽之後不計入，被別人更大的宣告搶先、還沒決定的那次也不算。

牌桌右側的「紀錄」一律預設收起來，只顯示最新一則，按右邊的箭頭或點那一行展開；箭頭朝下是展開、朝上是收合，滑鼠停著有說明。連線的牌桌下面空出來的地方是聊天，跟電腦打的一人房間也有，只是沒有人回：訊息列表、輸入框與「送出」，按 Enter 也送出。一則最多 100 字，服務器每人每 10 秒最多收 5 則，太快或內容不合會在聊天區下方顯示原因；舊服務器不認得聊天時顯示「這台服務器還不能聊天。」。聊天不保留歷史，斷線期間的訊息不補送，在房間畫面等人時收到的也不顯示。單機沒有服務器，沒有聊天。

## 擲骰子與牌牆

牌桌中央方框四邊名字的外面是牌牆：每家面前 18 墩、每墩上下兩張，共 144 張，四面像風車一樣各佔一個角。拿走的墩空出來，只剩下面那張的墩比較暗。棄牌排在牌牆外面。

每局開始時莊家擲三顆骰子，照台灣的習慣開門：

1. 三顆骰子從莊家面前邊轉邊跳到中央，0.65 秒停下來，下面亮出總點數，1 點與 4 點是紅色的。
2. 從莊家起照行牌順序數點數，莊家是 1，數到的那家開門；再從那家牌牆的右端數點數那麼多墩，牌牆上這裡有一條金線。
3. 1.1 秒後開始發牌：從開門處往順時針拿，每家每批四張輪流拿，最後是莊家的第 17 張，牌從牌牆上那一墩飛過去。中央的字等骰子淡出才出現。

之後一般摸牌從牌頭拿；補花與開槓後補的牌從開門處的另一邊，也就是牌尾拿。最後 16 張留著不摸，和以前一樣。紀錄會寫一行「莊家 擲出 4、5、2，共 11 點，從某某的牌牆開門」。「動畫」關閉時不演骰子與發牌，紀錄照寫，牌牆照畫。

骰子只決定從哪裡開門，不影響拿到什麼牌：牌牆是洗好的，從哪裡開門機率都一樣，所以引擎的 `Wall` 照舊只記牌頭與牌尾，畫面上的位置由 `engine.WallRing` 算，從局面看得到的剩餘張數、花牌與槓推回牌頭與牌尾各拿了幾張。

- **單機**：每局另外擲，不動牌局的亂數，同一個種子打出來的牌一樣。骰子不存檔，接回存檔時重新擲，開門的位置可能和存檔前不同。
- **連線**：服務器沒有送骰子，用房號、莊家的服務器座位、圈風、局風與連莊數算（`OnlineGame.dice`），同桌的人不管坐哪裡、用 Swing 還是網頁、斷線接回，看到的都一樣。同一間房間再開一場時，第一局可能和上一場一樣。服務器在 `roundStart` 之後留 3 秒（`dealMs`）才行牌，骰子加發牌約 2.4 秒，在這之內。

## 牌局存檔

存在使用者目錄的 `.ezmj\save.properties`，只有一份。刪除這個檔案就沒有可以繼續的牌局。

- 關閉視窗或按「離開牌局」時可以選存檔、不存檔或取消。不存檔會刪掉存檔。
- 每次輪到真人決定、每局結算完都會自動存，程式當掉時可以接回上一次輪到真人的時候。
- 開始畫面有存檔時會多一個「繼續上次的牌局」。開新局會蓋掉存檔，開之前會先問。牌局打完就刪掉存檔。
- 接回來時牌牆順序、手牌與整場的輸贏歷程都和原本一樣，有沒有用過電腦代打也會記得；電腦代打的開關回到關閉。之後新開的局用種子與局數換一組亂數，所以一樣是隨機的。
- 讀不懂或牌的張數不對的存檔不會接回，當作沒有存檔，原因記在 `.ezmj\error.log`。

強制結束程式的話，可以從上一次輪到真人的時候重打。這是單機遊戲，沒有特別防這件事。

## 錯誤記錄

沒有被處理的錯誤都記在使用者目錄的 `.ezmj\error.log`，連同時間、執行緒、這場的亂數種子與局面。一次執行最多記 20 筆，檔案超過 512 KB 就換成 `error.log.old` 重新開始。

畫面執行緒出錯時牌局的流程會斷掉，所以會跳出說明並回到開始畫面，牌局可以從存檔接著打。音效、語音這些背景執行緒的錯誤只記錄，不打斷牌局。

## 統計

選單「統計」列出真人玩家的累計成績：局數、胡牌率、自摸率、放槍率、胡牌平均台數與最高台數、累計輸贏、打完的場數、第一名與平均名次，也能依同桌的電腦等級分開看。同桌有兩種等級時兩邊都算，所以各等級的局數加起來會超過總計。

每局結算完就存到使用者目錄的 `.ezmj\stats.properties`，刪除這個檔案就清空。計算方式和成就一樣：開了電腦代打之後，這場剩下的局與整場都不列入，在那之前自己打完的局仍然算數。

## 成就

選單「成就」列出全部成就與達成日期，分成牌型、大牌、連續、累計、整場五類，還沒達成的累計成就會顯示進度。達成時會顯示在該局的結果視窗或牌局結束視窗。

成就都是看真人玩家的表現，每局結束就存到使用者目錄的 `.ezmj\achievements.properties`，重開遊戲後都還在，刪除這個檔案就清空。成就與累計次數每局記錄：開了電腦代打之後，這場剩下的局與整場類成就都不列入，在那之前自己打完的局仍然算數。中途離開的牌局也一樣，已經打完的局數算數，只是不會判定整場類的成就。

要新增成就，只要在 `Achievement` 裡加一項。

## 榮譽榜

選單「榮譽榜」記錄真人玩家的成績，胡牌數、自摸數、贏錢金額、放槍數各自留下最高的十筆，存在使用者目錄的 `.ezmj\honor.properties`，刪除這個檔案就清空。

牌局打到結束（四圈打完或有人輸光）才記錄，最後一局的結果視窗出現之前就會存檔，重開遊戲後紀錄還在。中途離開或用過電腦代打都不算。數值是 0 以下的類別不列入，數值相同時先達成的排前面。

## 八仙過海與七搶一

八張花牌都亮出來時立即胡，不看手牌，開局補花時也一樣，由程式自動宣告。

- **八仙過海**：一家集滿八張。算自摸，三家付錢。
- **七搶一**：一家七張、別家一張。七張的人拿走那張花，算那家放槍，只有他付錢。

兩種都是 8 台，不另計其他牌型，莊家台照一般規則加。

## 吃碰槓選牌

只有一種選擇時，按下吃、碰、槓就直接宣告；胡與自摸也是按了就胡。吃有多種組合、或自己回合有多張牌能槓時才進入選牌：能用的手牌維持原色，不能選的蓋上遮罩，點手牌就決定。吃牌時點共用的牌後再選一張。「取消」回到上一步，倒數不會重新計時。

亮出來的牌組排在手牌左邊，四家都是各自的左手邊。

**宣告的先後**：已經決定的宣告比每一位還在考慮的人能做的選項都大，就不再等他們，直接成立。大小只看種類：胡 > 槓、碰 > 吃，同樣是胡就照舊等。電腦、代打與報聽的人自動做的宣告，要等宣告開始 2 秒（`TableFlow.BOT_CLAIM_MS`）才算數，所以你只能吃、電腦要碰時，2 秒後電腦就先碰走，不用等你按。真人對真人也一樣。被搶先的人按鈕收起來，提示會寫「阿土 碰走了 三萬」。

**吃碰之後要打牌**：吃、碰、槓之後輪到自己打牌時，動作列的提示放大成金色粗體並一閃一閃（每 0.45 秒換一次金色與白色），自己的手牌外框也亮起金色圓角框，一明一暗，週期 1 秒，直到打出牌。

## 報聽與電腦代打

**報聽**：照常打牌，打出之後剩下的手牌已經聽牌、還沒報聽，動作列就多一個「聽牌」按鈕。機會一直到這位玩家下一次摸牌、吃碰槓或這局結束，放棄別家打出的牌不影響。按下就進入原本的聽牌模式：手牌鎖定，自動摸打、自動胡，不再吃碰槓。和以前不同的是報聽是公開的：全桌都看得到，那位玩家中央方框那一邊的名字右端有紅底金框的圓形「聽」，報聽時跳出「報聽」的大字，「聽」從 2.4 倍大彈回原本大小，外面兩個金圈擴散，共 0.9 秒。胡牌時多算「聽牌」1 台，自摸或胡別家的牌都算，也算在牌型合計裡，所以會影響 10 台以上的大胡。

電腦也會報聽：初學者不報；一般只看聽幾種，聽兩種以上才報（愛衝與愛做大牌一聽就報、保守的單騎不報）；業餘數全桌扣完後還剩幾張能胡；職業另外考慮報了就不能換聽、不能防守，別家也會防著打，底大台小或別家看起來已經聽牌時要更多張才報。職業與業餘看得到別家公開的報聽，報聽的人一定算聽牌，估台數也多 1 台。

存檔會記下誰報聽了、誰還有報聽的機會。以前的存檔只記自己聽牌模式等的牌，讀回來當作自己報聽了。

**電腦代打**：單機牌桌右側的開關，隨時可以開關，由職業等級的電腦替玩家決定。多人遊戲沒有這個開關。電腦一樣只拿得到 `TableView`，只看得到該座位合法的資訊。

## 電腦等級

開始畫面可以替右家、對家、左家各選一個等級，預設都是一般。榮譽榜會記下這場的等級，三家不同時依右家、對家、左家的順序列出。成就「勝過職業」要三家都是職業才算。四個等級拿到的牌與規則完全一樣，差別只在看多少資訊、想多少：

| 等級 | 看什麼 | 怎麼想 |
|---|---|---|
| 初學者 | 只看自己手牌 | 打看起來連不起來的牌，能吃就吃、能碰就碰 |
| 一般 | 只看自己的牌 | 算還差幾步聽牌，吃碰會想有沒有變快；不數張數、不防守 |
| 業餘 | 加上全桌打出與亮出的牌 | 快聽牌時用真正剩下的張數算進張；有人快聽時挑現物與筋，差太遠就保命 |
| 職業 | 加上打牌順序、花色傾向、籌碼規則與各家籌碼 | 估各家聽牌機率與放槍風險、估這手值幾台，用期望金額決定攻或守；最後一圈明顯領先就守、明顯落後就拚，籌碼快輸光就保命 |

每家電腦開局時隨機一種個性，滑鼠停在牌桌右側的名字上可以看。個性和等級無關，是同樣的局面偏向哪邊，存檔接回後不會變：

| 個性 | 怎麼打 |
|---|---|
| 穩健 | 照該等級原本的算法 |
| 愛衝 | 比較敢攻，晚一點才防守或棄胡 |
| 保守 | 比較早防守，不輕易吃牌 |
| 愛做大牌 | 為了一色、刻子與門清願意慢一點，不輕易吃牌 |

初學者憑感覺打，沒有個性之分。`Tournament` 與電腦代打都用穩健。

**不作弊**：策略只拿得到 `TableView`，裡面只有該座位合法看得到的資訊，別家手牌、別家暗槓與牌牆順序在結構上就讀不到。`BotTest` 會在實際牌局中調換別家的暗牌，確認每個等級的決定都不受影響。

職業等級用到的統計表（`OpponentRead`、`ProStrategy` 裡的常數）是離線用大量自我對戰統計出來的，對局時只查表。個性與籌碼局勢的比重在 `Posture`。

各等級的對戰成績可以這樣看，引數是每組局數：

```
java -cp build\classes;build\test-classes ezmj.Tournament 4000
```
